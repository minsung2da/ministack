# Phase 2 — UI Design Contract

> Visual and interaction contract for the EC2 Dashboard & CRUD Patterns phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Inheritance:** This contract inherits the design system, spacing, typography, and color contracts from Phase 1 (`01-UI-SPEC.md`). Phase 2 extends with new Cloudscape components (Table, SplitPanel, Wizard, Modal, PropertyFilter, Tabs, Pagination) but does not change the foundational tokens. All values come from `@cloudscape-design/design-tokens` v3 — never hardcode px or hex literals.

| Token | Value | Usage |
|-------|-------|-------|

Same exceptions as Phase 1 UI-SPEC (approved). No new non-standard values introduced in Phase 2.

## Wizard Contract — Instance Launch (CRUD-03, EC2-06, D-08)

Cloudscape `Wizard` component with 4 steps.

| Step | Title | Fields | Notes |
|------|-------|--------|-------|
| 1 | Name and instance type | Name (Input, optional), Instance type (Select, required) | Instance types populated from hardcoded list: t2.micro, t2.small, t2.medium, t2.large, t3.micro, t3.small, t3.medium, t3.large, m5.large, m5.xlarge |

| 3 | Security | Security groups (Multiselect, at least 1 required), Key pair (Select, optional) | SG list filtered by selected VPC, key pair list from API |
| 4 | Review and launch | Read-only summary of all selections | Primary CTA: "Launch instance" |

**Wizard behavior:**
- Cancel returns to Instances tab without creating anything
- Each step validates before allowing "Next"
- "Launch instance" button is `variant="primary"` and disabled until all required fields are filled
- On success: Flashbar success message, navigate to Instances tab, new instance appears in table
- On error: Flashbar error message, wizard stays open on Review step

## Delete Confirmation Contract (CRUD-04, D-10)

Type-to-confirm pattern for all destructive actions.

| Property | Value |
|----------|-------|
| Component | Cloudscape `Modal` |
| Confirm mechanism | User must type the resource ID to enable the delete button |
| Delete button | `variant="primary"` with Cloudscape destructive color override via `data-testid` (Cloudscape does not have a `variant="destructive"` — use normal primary with red text via `color="text-status-error"` on the button label) |

All user actions produce feedback via Cloudscape `Flashbar` at the top of the content area.

- Maximum 3 visible notifications at once (oldest dismissed first)

- All notifications have a dismiss (X) button
- Error notifications never auto-dismiss
