   - `parseVpcs(xml: string): Ec2Vpc[]` — parse DescribeVpcs XML. VPCs are in `vpcSet > item`. For each item extract: vpcId, state, cidrBlock, isDefault (`getText(el, 'isDefault') === 'true'`), dhcpOptionsId, instanceTenancy, nameTag via `getNameTag(el)`, cidrBlockAssociations: from `cidrBlockAssociationSet > item`, each with `getText(item, 'cidrBlock')` and status from `cidrBlockState > state`.
   - `useVpcs()` — queryKey `['ec2', 'vpcs']`, staleTime 30_000
   - `useCreateVpc()` — mutation calling `ec2Query('CreateVpc', { CidrBlock: cidr })`. If nameTag provided, follow with `ec2Query('CreateTags', { 'ResourceId.1': newVpcId, 'Tag.1.Key': 'Name', 'Tag.1.Value': nameTag })`. Invalidate `['ec2', 'vpcs']`. Parse response to extract vpcId for Flashbar message.
   - `useDeleteVpc()` — mutation calling `ec2Query('DeleteVpc', { VpcId: vpcId })`. Invalidate `['ec2', 'vpcs']`.

2. Create `web/src/services/ec2/api/subnets.ts`:
   - `parseSubnets(xml: string): Ec2Subnet[]` — parse DescribeSubnets XML. Subnets in `subnetSet > item`. Extract: subnetId, state, vpcId, cidrBlock, availabilityZone, availableIpAddressCount (parse as number), nameTag, mapPublicIpOnLaunch (`getText(el, 'mapPublicIpOnLaunch') === 'true'`).
   - `useSubnets()` — queryKey `['ec2', 'subnets']`, staleTime 30_000
   - `useCreateSubnet()` — mutation: `ec2Query('CreateSubnet', { VpcId, CidrBlock, AvailabilityZone })`. Optional Name tag via CreateTags. Invalidate `['ec2', 'subnets']`.
   - `useDeleteSubnet()` — mutation: `ec2Query('DeleteSubnet', { SubnetId })`. Invalidate `['ec2', 'subnets']`.

3. Create `web/src/services/ec2/api/securityGroups.ts`:
   - `parseSecurityGroups(xml: string): Ec2SecurityGroup[]` — parse DescribeSecurityGroups XML. SGs in `securityGroupInfo > item`. Extract: groupId, groupName, vpcId, groupDescription (`getText(el, 'groupDescription')`), nameTag.
   - For inbound rules: from `ipPermissions > item`, extract protocol (`getText(item, 'ipProtocol')`), portRange (`fromPort` + `-` + `toPort`, or `'All'` if protocol is `-1`), source (from `ipRanges > item > cidrIp` or `groups > item > groupId`), description.
   - For outbound rules: same from `ipPermissionsEgress > item`.
   - `useSecurityGroups()` — queryKey `['ec2', 'security-groups']`, staleTime 30_000
   - `useCreateSecurityGroup()` — mutation: `ec2Query('CreateSecurityGroup', { GroupName, GroupDescription, VpcId })`. Invalidate `['ec2', 'security-groups']`. Parse response for groupId.
   - `useDeleteSecurityGroup()` — mutation: `ec2Query('DeleteSecurityGroup', { GroupId })`. Invalidate `['ec2', 'security-groups']`.
