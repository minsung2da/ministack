1. Create `web/src/shared/api/xml.ts` with these exports:
   - `parseXml(text: string): Document` — wraps `new DOMParser().parseFromString(text, 'application/xml')`
   - `getText(el: Element, tag: string): string` — returns `el.getElementsByTagName(tag)[0]?.textContent ?? ''`
   - `getItems(parent: Document | Element, setTag: string): Element[]` — gets the FIRST element matching `setTag`, then returns `Array.from(firstSet.getElementsByTagName('item'))`. Returns `[]` if setTag not found. This avoids the cross-nesting pitfall where `getElementsByTagName('item')` from doc root returns items from ALL sets.
   - `getNameTag(el: Element): string` — searches `el`'s tagSet for an `<item>` where `<key>` is `Name`, returns its `<value>` text. Returns `''` if no Name tag.
   - `getAllItemsFromSet(parent: Document | Element, setTag: string): Element[]` — same as getItems but exported for cases where the parent is already scoped.

POSTs to `${ORIGIN}/` with headers `Content-Type: application/x-www-form-urlencoded` and `Authorization: AWS4-HMAC-SHA256 Credential=test/20260407/us-east-1/ec2/aws4_request`. Returns `.text()`.
