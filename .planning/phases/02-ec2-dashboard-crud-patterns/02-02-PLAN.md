   - In AppLayout, add props: `splitPanel={ctx.isOpen ? <SplitPanel header={ctx.header}>{ctx.panel}</SplitPanel> : null}`, `splitPanelOpen={ctx.isOpen}`, `onSplitPanelToggle={({ detail }) => detail.open ? undefined : ctx.closePanel()}`, `splitPanelPreferences={{ position: 'bottom' }}`, `onSplitPanelPreferencesChange={() => {}}` (lock to bottom per D-06)

   - Renders `<StatusIndicator type={EC2_STATE_MAP[state] ?? 'info'}>{state}</StatusIndicator>`
   - Export the `EC2_STATE_MAP` for reuse

5. Create `web/src/services/ec2/components/DeleteModal.tsx`:

   - Uses Cloudscape Modal, Alert (type="warning"), FormField, Input, Button, SpaceBetween
   - Single delete: user must type the exact resourceId. Placeholder: `Type "${resourceId}" to confirm`
   - Bulk delete: user must type "delete" (or "terminate" for instances). Placeholder: `To confirm deletion, type "delete"`
   - Delete button is `variant="primary"` and disabled until confirmValue matches
   - Copy from `copy.ts` ec2Delete* entries

   - Width prop: `size` defaults to 'medium' (600px). Accept 'small' (480px) via optional prop.
   - On error: shows Alert type="error" above form via optional `error` prop

7. Create `web/src/services/ec2/components/SplitPanelDetail.tsx`:
   - Props: `header: string`, `tabs?: Array<{id: string; label: string; content: ReactNode}>`, `keyValueItems?: Array<{label: string; value: ReactNode}>`
   - If `tabs` provided: renders Cloudscape Tabs inside the panel content
   - If `keyValueItems` provided: renders Cloudscape KeyValuePairs in ColumnLayout (2 columns)
   - This is the content INSIDE the SplitPanel (the SplitPanel wrapper itself is in ConsoleShell)

8. Create `web/src/services/ec2/components/FlashNotifications.tsx`:
   - Export `useFlashNotifications()` hook using useState to manage a `FlashbarProps.MessageDefinition[]` array
   - Returns `{ items, addSuccess(message), addError(message), clearAll() }`
   - `addSuccess`: pushes item with `type: 'success'`, `dismissible: true`, `dismissLabel: 'Dismiss'`, auto-dismiss after 5000ms via setTimeout + filter
   - `addError`: pushes item with `type: 'error'`, `dismissible: true`, no auto-dismiss
   - Max 3 visible: if items.length >= 3, remove oldest before pushing
   - Export `FlashNotifications` component that renders `<Flashbar items={items} />`

     - `resourceType: string` (for copy lookups)
     - `filteringProperties: PropertyFilterProps.FilteringProperty[]`
     - `selectedItems: T[]`, `onSelectionChange: (items: T[]) => void`
     - `onRowClick?: (item: T) => void`
     - `headerActions?: ReactNode` (action buttons + create button + refresh)
     - `selectionType?: 'multi' | 'single' | 'none'` (default 'multi')
     - `useTextFilter?: boolean` (for list-only resources that use TextFilter instead of PropertyFilter)

   - Page size from `useUiStore` `ec2PageSize`
   - Renders: Header with counter + headerActions, PropertyFilter (or TextFilter), Table with collectionProps, Pagination, CollectionPreferences (page sizes 10/25/50)

   - No match state uses ec2NoMatchHeading/Body/Cta from copy.ts
   - Row click: if `onRowClick` provided, `onRowClick(item)` on row click (distinct from checkbox selection)
