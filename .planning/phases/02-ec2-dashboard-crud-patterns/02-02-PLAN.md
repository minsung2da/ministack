Create `web/src/services/ec2/api/instances.ts` with:

1. `parseInstances(xml: string): Ec2Instance[]` function:
   - Call `parseXml(xml)` to get Document
   - Get all reservations: `getItems(doc, 'reservationSet')`
   - For EACH reservation item, get instances: get the `instancesSet` element within the reservation, then get its `item` children
   - CRITICAL: Do NOT use `doc.getElementsByTagName('item')` — it returns ALL items across all nesting levels. Instead: for each reservation item, find its `instancesSet` child, then get `item` elements from that specific set.
   - For each instance element, extract:
     - instanceId: `getText(el, 'instanceId')`
     - instanceType: `getText(el, 'instanceType')`
     - state: navigate to `instanceState` child element, then get `name` text from it. Use `el.getElementsByTagName('instanceState')[0]?.getElementsByTagName('name')[0]?.textContent ?? 'unknown'`
     - availabilityZone: `el.getElementsByTagName('placement')[0]?.getElementsByTagName('availabilityZone')[0]?.textContent ?? ''`
     - publicIpAddress, privateIpAddress, vpcId, subnetId, keyName, imageId, architecture, platform: all via `getText(el, tagName)`
     - nameTag: `getNameTag(el)` — searches tagSet for Name key
     - launchTime: `getText(el, 'launchTime')`
     - securityGroups: from the instance element's `groupSet`, get `item` children, map each to `{ groupId: getText(sg, 'groupId'), groupName: getText(sg, 'groupName') }`
     - monitoring: `el.getElementsByTagName('monitoring')[0]?.getElementsByTagName('state')[0]?.textContent ?? 'disabled'`
     - privateDnsName, publicDnsName: via getText
     - rootDeviceName, rootDeviceType: via getText
     - blockDeviceMappings: from `blockDeviceMapping` set, get items, map to `{ deviceName: getText(item, 'deviceName'), volumeId: item.getElementsByTagName('ebs')[0] ? getText(item.getElementsByTagName('ebs')[0]!, 'volumeId') : '' }`
     - iamInstanceProfile: `getText(el, 'iamInstanceProfile')` (may be empty)

2. `useInstances()` — TanStack Query hook:
   - `queryKey: ['ec2', 'instances']`
   - `queryFn`: calls `ec2Query('DescribeInstances')` then `parseInstances(xml)`
   - `staleTime: 30_000`

3. `useStartInstances()` — TanStack Mutation hook:
   - `mutationFn: (instanceIds: string[])` — builds params with `addMemberList(params, 'InstanceId', instanceIds)`, calls `ec2Query('StartInstances', params)`
   - `onSuccess`: invalidate `['ec2', 'instances']`

4. `useStopInstances()` — same pattern with `StopInstances`

5. `useTerminateInstances()` — same pattern with `TerminateInstances`

6. `useRebootInstances()` — same pattern with `RebootInstances`

All mutation hooks use `useQueryClient()` to get the query client for invalidation.
