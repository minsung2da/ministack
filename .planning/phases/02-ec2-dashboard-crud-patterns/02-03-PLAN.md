1. Create `web/src/services/ec2/api/images.ts`:
   - Define type `Ec2Image = { imageId: string; name: string; description: string; architecture: string; platform: string }`
   - `parseImages(xml: string): Ec2Image[]` — parses DescribeImages XML response. Images are in `imagesSet > item`.
   - `useImages()` hook — queryKey `['ec2', 'images']`, calls `ec2Query('DescribeImages')`, staleTime 300_000 (5 min, images rarely change)
   - Backend provides 3 stub AMIs: Amazon Linux 2, Ubuntu 22.04, Windows Server 2022

2. Add to `web/src/services/ec2/api/instances.ts` (if not already present):
   - `useRunInstance()` mutation hook:
     - `mutationFn` accepts `{ imageId: string; instanceType: string; subnetId: string; securityGroupIds: string[]; keyName?: string; nameTag?: string; minCount?: number; maxCount?: number }`
     - Builds params: `ImageId`, `InstanceType`, `SubnetId`, `MinCount: '1'`, `MaxCount: '1'`
     - If keyName: `params.KeyName = keyName`
     - If securityGroupIds: `addMemberList(params, 'SecurityGroupId', securityGroupIds)`
     - If nameTag: `params['TagSpecification.1.ResourceType'] = 'instance'`, `params['TagSpecification.1.Tag.1.Key'] = 'Name'`, `params['TagSpecification.1.Tag.1.Value'] = nameTag`
     - Calls `ec2Query('RunInstances', params)`
     - `onSuccess`: invalidate `['ec2', 'instances']`
   - Also export API hooks needed by the wizard: reuse vpcs/subnets/sgs/keyPairs hooks from their respective API files (Plans 04-05 create these). For the wizard, create TEMPORARY inline hooks here:
     - `useVpcsForWizard()` — queryKey `['ec2', 'vpcs']`, calls `ec2Query('DescribeVpcs')`, parses vpcSet items for vpcId, cidrBlock, nameTag, state, isDefault
     - `useSubnetsForWizard()` — queryKey `['ec2', 'subnets']`, calls `ec2Query('DescribeSubnets')`, parses subnetSet items for subnetId, vpcId, cidrBlock, availabilityZone, nameTag
     - `useSecurityGroupsForWizard()` — queryKey `['ec2', 'security-groups']`, calls `ec2Query('DescribeSecurityGroups')`, parses securityGroupInfo items
     - `useKeyPairsForWizard()` — queryKey `['ec2', 'key-pairs']`, calls `ec2Query('DescribeKeyPairs')`, parses keySet items
     NOTE: When Plans 04/05 create the full hooks, the wizard imports should be updated to use those instead. For now, these temporary hooks avoid a circular dependency.

   - Uses Cloudscape `Wizard` component with 4 steps
   - State: `activeStepIndex` (number), form values in a single state object:
     ```
     { name: '', instanceType: '', imageId: '', vpcId: '', subnetId: '',
       autoAssignPublicIp: 'Enable', securityGroupIds: string[], keyName: '' }
     ```

   **Step 1: Name and instance type** (per UI-SPEC Wizard Contract)
   - FormField "Name" — Input, optional, max 255 chars
   - FormField "Instance type" — Select, required. Options hardcoded:
     `t2.micro, t2.small, t2.medium, t2.large, t3.micro, t3.small, t3.medium, t3.large, m5.large, m5.xlarge`
   - Validate: instanceType must be selected before allowing "Next"

   **Step 2: Network settings**
   - FormField "VPC" — Select, required. Options from `useVpcsForWizard()`, display: `${vpc.vpcId} (${vpc.cidrBlock})${vpc.nameTag ? ' — ' + vpc.nameTag : ''}`
   - FormField "Subnet" — Select, required. Options filtered by selected VPC from `useSubnetsForWizard()`, display: `${subnet.subnetId} (${subnet.availabilityZone})${subnet.nameTag ? ' — ' + subnet.nameTag : ''}`
   - FormField "Auto-assign public IP" — Select with options Enable/Disable
   - When VPC changes: clear subnetId (subnet list re-filtered)

   **Step 3: Security**
   - FormField "Security groups" — Multiselect, at least 1 required. Options filtered by selected VPC from `useSecurityGroupsForWizard()`, display: `${sg.groupId} — ${sg.groupName}`
   - FormField "Key pair" — Select, optional. Options from `useKeyPairsForWizard()`, display: `${kp.keyName}`
   - Validate: at least 1 security group selected

   **Step 4: Review and launch**
   - Read-only summary using Cloudscape `ColumnLayout` + `KeyValuePairs`:
     - Name, Instance type, Image ID, VPC, Subnet, Public IP, Security groups (comma-separated names), Key pair
   - No form fields on this step

   **Wizard behavior:**
   - `onCancel`: navigate to `/services/ec2/instances` using `useNavigate()`
   - `onSubmit`: call `useRunInstance().mutateAsync(...)` with form values. On success: addSuccess flash, navigate to `/services/ec2/instances`. On error: addError flash, stay on review step.
   - "Launch instance" button label via `copy.ec2WizardSubmit`
   - Header: `copy.ec2WizardHeader` ("Launch an instance")
   - Each step validates required fields. `isLoadingNextStep` shows spinner during data fetch.
